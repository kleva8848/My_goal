# My_goal — Фін трекер

Telegram-бот: пишеш `-390 ютуб` → 👍 і запис у Supabase. Більше нічого не відповідає, лише коли щось важливе (ліміт категорії, мінус у плані, закритий борг).

- **Логіка** — повністю в Supabase: `supabase/001_fin_tracker.sql` (тригер на `fin_inbox` повертає `reaction` + `reply`)
- **n8n** — лише транспорт: `n8n/build_fin_tracker.mjs` → `n8n/fin_tracker.json` (11 вузлів)

## Запуск (≈10 хв)

1. **Supabase** → SQL Editor → виконати `supabase/001_fin_tracker.sql`
2. **BotFather** → новий бот, токен. Для групи: `/setprivacy` → Disable (інакше бот не бачить повідомлень)
3. **n8n**:
   - env контейнера (EasyPanel): `FIN_TG_TOKEN=<токен>` — потрібен для реакцій
   - Import → `n8n/fin_tracker.json`, вибрати креди Telegram + Supabase (service role) у 3 вузлах
   - Activate
4. Написати боту `/start` — **перший чат, що написав, стає власником**, решта ігнорується
5. Налаштувати один раз:
   ```
   залишок 20000
   дохід 30000
   категорія їжа 8000 сільпо атб обід
   категорія підписки 500 ютуб нетфлікс
   категорія комуналка 3000 !
   борг тас 25000 3000 таскомбанк
   ціль резина 8000 01.03.2027
   ```

## Команди

| Пишеш | Що буде |
|---|---|
| `-390 ютуб`, `-2к сільпо`, `-1 500 атб` | витрата. 👍 = категорія знайдена, 👌 = пішло в «інше» |
| `+5000 зп` | дохід 🔥. Що понад план місяця — 80% радить на борги, 20% на життя |
| `-3000 тас` | платіж по боргу (слово = назва/аліас боргу). Борг у 0 → 🎉 мотивашка |
| `-8000 резина` | оплата цілі (відкладені гроші списуються) |
| `відміна` | видалити останній запис; відповіддю на повідомлення — саме його |
| `залишок N` | фактичні гроші зараз — від цього рахується все |
| `дохід N` | план доходу на місяць |
| `категорія назва ліміт [слова…] [!]` | ліміт/міс + слова для автокатегорії; `!` = обов'язкова (не радити урізати) |
| `борг назва залишок [платіж] [слова…]` | кредитка/розстрочка |
| `ціль назва сума дд.мм[.рррр]` | обов'язкова витрата наперед: щомісяця відкладає `сума / місяців` |
| `можу 5000` / `чи можу 5000?` | чи потягнеш без нового доходу, і що конкретно урізати |
| `стан` · `звіт` · `план` · `допомога` | гроші/вільно · звірка · план місяця · шпаргалка |

Після **25-го** `дохід` / `категорія` пишуться в план **наступного** місяця (поточний не ламається).

## Розклад (Europe/Kyiv)

- **Нд 19:00** — звірка: витрати за тиждень по категоріях, % залишку, борги, цілі, «вільно до кінця місяця»
- **27-го 10:00** — нагадування скласти план наступного місяця (показує поточний)
- **1-го 09:00** — підсумок місяця + просить `залишок N`; внески в цілі переходять у «відкладено»

## Як рахується «вільно»

```
вільно = гроші зараз + ще очікуваний дохід
       − залишки лімітів категорій
       − ще не сплачені платежі по боргах
       − цілі (відкладене + внесок цього місяця)
       − 80% додаткового доходу, ще не кинуті на борги
```
`< 0` → 🚨 одразу повідомлення (один раз на перетин). Категорія ≤25% → ⚠️, перевищена → 🔴 (по разу на місяць).

Налаштування — таблиця `fin_settings`: `debt_share` (80), `warn_pct` (25), `plan_from_day` (25), `tz`, `owner_chat_id`.
