# My_goal — пошук клієнтів для AI Systema

## Контекст
- Влад, засновник **AI Systema**: екосистеми AI-агентів для бізнесу (бухгалтерія «Галя», контент, продажі).
- Стек: n8n (основне), Supabase, Lovable/React, Vercel, EasyPanel, VPS Contabo.
- Живий кейс: **TravelLab** (репо `kleva8848/travellab-approve`): контент-агент, апрув постів у Telegram Mini App, агент вчиться на правках власниці.
- **Ціль:** 1–2 нових клієнти на місяць через максимально автоматизовану систему пошуку.

## Де що лежить
- `docs/client-acquisition/system-plan.md`: **майстер-план** (модулі M1–M9, фази F0–F6). Починати звідси.
- `docs/client-acquisition/brainstorm.md`: усі ідеї з брейншторму (канали, сигнали, оффери, контент).
- `docs/client-acquisition/lead-engine-vacancies.md`: детальний план головної ідеї «Вакансії як сигнал».
- `docs/client-acquisition/lead-engine-maps-sites.md`: план «Google Maps → готовий демо-сайт».
- `docs/client-acquisition/backlog.md`: що робимо по черзі, статуси.

## Як продовжувати
Коли Влад каже «давай робити ідею X»:
1. Прочитай `backlog.md` і потрібний документ.
2. Уточни тільки те, чого бракує (ключі API, ніша, ціна).
3. Код і воркфлоу клади в `lead-engine/` (n8n JSON, SQL-міграції Supabase, скрипти).
4. Онови статус у `backlog.md`.

## Правила
- Мова: українська, коротко, без води.
- Жодних токенів/ID у коді: тільки env.
- Ніякої масової автовідправки з особистих акаунтів: чернетка → апрув Влада → ручна відправка.
