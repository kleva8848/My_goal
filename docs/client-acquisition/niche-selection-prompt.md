```

2. Клієнти шукають саме в Google («послуга + район»), а не тільки в Instagram.
3. Власник досяжний: малий бізнес на 1–20 людей, без мережі/франшизи.

5. Є очевидний апсейл на автоматизацію: запис, заявки, повторні продажі, відгуки.
6. Багато таких бізнесів у Києві (≥ 200), щоб вистачило на місяці.
7. Українські реалії: війна, сезонність, платоспроможність.

Що зроби:

- Будь критичним: якщо ніша слабка, скажи прямо.

Відповідай українською, коротко, таблицями, без води.
```
