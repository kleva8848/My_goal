# Lead Engine: «Google Maps → готовий сайт»

## Ідея
Бізнес з купою відгуків, але без сайту = живий бізнес, який втрачає пошуковий трафік. Генеруємо сайт **до першого контакту** і пишемо: «Я вже зробив вам сайт, ось посилання».
Сайт ($200–300) = вхідний квиток. Гроші далі: підтримка/хостинг щомісяця + онлайн-запис + AI-бот у Direct/Telegram + відповіді на відгуки.

## Пайплайн
```
Apify Google Maps Scraper / Google Places API (Київ, ніша)
 → Фільтр: немає сайту (або «сайт» = Instagram/Facebook), відгуків ≥ 50, рейтинг ≥ 4.3
 → Supabase `places` (дедуп по place_id)
 → Claude: тексти (послуги, переваги з відгуків, FAQ), стиль під нішу
 → Шаблон one-page (React/Astro) → деплой на піддомен demo-<slug>.<наш домен>
 → Трекінг відкриття сторінки → нотифікація в TG «власник відкрив сайт» 🔥
 → Чернетка повідомлення → апрув → ручна відправка (Viber/Telegram/дзвінок)
```

## Ніші для старту (Київ)
Стоматології, СТО/шиномонтаж, б'юті-салони/барбершопи, ремонт техніки, ветклініки, клінінг, репетитори/студії. Пріоритет: там, де клієнти **шукають у Google** (СТО, стоматологія, ремонт), а не тільки в Instagram.

## Гачок у повідомленні
«У вас 230 відгуків і 4.8 ⭐, але на запит "стоматологія Оболонь" клієнти бачать тих, у кого є сайт. Я зробив вам сторінку з вашими відгуками та записом: <лінк>. Сподобається — 6–9 тис. грн, і вона ваша з доменом».

## Правила (обов'язково)
- Демо-сайт: банер «Демо-концепт, не офіційний сайт», `noindex`, без чужих логотипів як офіційних. Інакше вийде імперсонація, і клієнти бізнесу заплутаються.
- Фото: краще плейсхолдери/стокові; фото з Maps тільки після згоди власника.
- Відгуки цитуємо як «з Google», з ім'ям автора, без вигадок.
- Відправка тільки вручну.

## Економіка (оцінка, перевірити тестом)
100 сайтів → 100 повідомлень → 5–10% відповідей → 2–5 продажів × $250 + апсейл бота/підтримки.
Собівартість сайту ≈ токени + хвилини часу.

## Тест
Тиждень 1: 1 ніша, 30 демо-сайтів, 30 повідомлень/дзвінків. Міряємо: відкриття лінку, відповіді, продажі.
