# Lead Engine: «Google Maps → готовий сайт»

## Ідея
Бізнес з купою відгуків, але без сайту = живий бізнес, який втрачає пошуковий трафік. Генеруємо сайт **до першого контакту** і пишемо: «Я вже зробив вам сайт, ось посилання».
Сайт ($200–300) = вхідний квиток. Гроші далі: підтримка/хостинг щомісяця + онлайн-запис + AI-бот у Direct/Telegram + відповіді на відгуки.

## Пайплайн
```
Apify Google Maps Scraper / Google Places API (Київ, ніша)
 → Фільтр: немає сайту (або «сайт» = Instagram/Facebook), відгуків ≥ 50, рейтинг ≥ 4.3
 → Supabase `places` (дедуп по place_id)
 → Claude: тексти (послуги, переваги з відгуків, FAQ), стиль під нішу
 → Шаблон one-page (React/Astro) → деплой на піддомен demo-<slug>.<наш домен>
 → Трекінг відкриття сторінки → нотифікація в TG «власник відкрив сайт» 🔥
 → Чернетка повідомлення → апрув → ручна відправка (Viber/Telegram/дзвінок)
```

## Ніші для старту (Київ)
Стоматології, СТО/шиномонтаж, б'юті-салони/барбершопи, ремонт техніки, ветклініки, клінінг, репетитори/студії. Пріоритет: там, де клієнти **шукають у Google** (СТО, стоматологія, ремонт), а не тільки в Instagram.

## Гачок у повідомленні
«У вас 230 відгуків і 4.8 ⭐, але на запит "стоматологія Оболонь" клієнти бачать тих, у кого є сайт. Я зробив вам сторінку з вашими відгуками та записом: <лінк>. Сподобається — 6–9 тис. грн, і вона ваша з доменом».

## Правила (обов'язково)
- Демо-сайт: банер «Демо-концепт, не офіційний сайт», `noindex`, без чужих логотипів як офіційних. Інакше вийде імперсонація, і клієнти бізнесу заплутаються.
- Фото: краще плейсхолдери/стокові; фото з Maps тільки після згоди власника.
- Відгуки цитуємо як «з Google», з ім'ям автора, без вигадок.
- Відправка тільки вручну.

## Економіка (оцінка, перевірити тестом)
100 сайтів → 100 повідомлень → 5–10% відповідей → 2–5 продажів × $250 + апсейл бота/підтримки.
Собівартість сайту ≈ токени + хвилини часу.

## Тест
Тиждень 1: 1 ніша, 30 демо-сайтів, 30 повідомлень/дзвінків. Міряємо: відкриття лінку, відповіді, продажі.

## Архітектура без спалювання лімітів
- **Claude Code (підписка)** використовуємо тільки для **розробки системи** один раз: шаблони, n8n, Supabase.
- **Масова генерація** йде через API дешевої моделі в n8n (Haiku / Gemini Flash / gpt-mini) з окремим pay-as-you-go ключем.
- Модель генерує **тільки JSON-контент** (тексти, послуги, FAQ, вибрані відгуки), а не код сайту. ~5–10k токенів ≈ центи за сайт.
- **Один деплой на всіх:** Next/Astro з маршрутом `/[slug]`, контент береться з Supabase. Новий сайт = новий рядок у БД, без окремого деплою.
- Фото зі стоку (Unsplash API) або плейсхолдери. Генерацію картинок не використовуємо.
- Демо генеруємо тільки для лідів зі score ≥ 7.
- Повноцінний сайт для клієнта, що заплатив, робимо вже в Claude Code або на сильнішій моделі.

## Масштаб: ліди не закінчаться
- Вузьке місце — твій час (дзвінки, здача робіт), а не кількість лідів. 10 контактів на день = ~250 на місяць, тобто 10k вистачить на роки.
- Нові джерела: нові ніші, інші міста (Львів, Одеса, Дніпро, Харків…), нові бізнеси щомісяця, повторний контакт через 3–6 місяців, бізнеси українців у Польщі/ЄС.
- Інші сигнали для тієї ж бази: старий сайт, немає онлайн-запису, невідповідені відгуки.

## Сходинки апсейлу
Сайт → оптимізація Google Business Profile → відповіді на відгуки → онлайн-запис → ліди в Telegram → локальне SEO (сторінки під райони/послуги) → щомісячний звіт → AI-агенти (Direct-бот, бухгалтерія).
Варіант оферу: **«сайт за 0 грн + 500–800 грн/міс»** (менше тертя, recurring).

## Як JSON перетворюється на сайт і де унікальність
- Одна Next.js/Astro апка на Vercel. Маршрут `/[slug]` бере JSON бізнесу із Supabase і збирає сторінку з **бібліотеки секцій**.
- n8n + дешева модель пише JSON: контент і **вибір дизайну** (layout, палітра, шрифти, порядок секцій).
- Варіативність: ~5 layout × 8 палітр × 4 пари шрифтів × різний порядок секцій під нішу → сотні комбінацій. Палітра береться з логотипу чи фото бізнесу.
- Справжня унікальність у контенті: назва, район, їхні послуги й ціни, їхні відгуки з іменами, їхні години, карта, FAQ з питань у відгуках. Власник бачить тільки свій сайт і не порівнює його з чужими.
- **Premium-демо** для топ-лідів (score 9+): Claude Code робить повністю кастомний сайт, 3–5 на тиждень.

## Ціни (замість «0 + 500 грн»)
- **Старт:** сайт + домен + Google Business Profile, 6–9 тис. грн разово.
- **Ріст:** сайт + онлайн-запис + заявки в TG + відповіді на відгуки, 12–15 тис. грн + 1 500–2 500 грн/міс.
- **Агент:** Direct-бот / AI-адміністратор, від 3–5 тис. грн/міс.
- Аргумент ROI: «один пацієнт імплантації = 20–40 тис. грн, сайт окупиться одним клієнтом».
