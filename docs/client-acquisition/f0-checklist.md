# F0: що потрібно від Влада для старту

## Рішення
- [ ] **Ніша для тесту:** стоматології / СТО / косметологія / ветклініки / інше
- [ ] **Місто й район:** Київ (Оболонь? весь Київ?)
- [ ] **Тарифи:** підтвердити або змінити Старт / Ріст / Агент (див. `lead-engine-maps-sites.md`)
- [ ] **Кейс TravelLab:** можна публічно з назвою чи тільки анонімно
- [ ] **Канал відправки:** Telegram / Viber / дзвінок / особистий візит

## Доступи (тільки в env або налаштуваннях середовища, НЕ в чат і НЕ в код)
- [ ] **Apify API token** (Google Maps Scraper; є безкоштовний ліміт) або **Google Places API key**
- [ ] **Google PageSpeed Insights API key** (безкоштовний, для аудиту сайтів)
- [ ] **API-ключ дешевої моделі** для масової генерації (Claude Haiku / Gemini Flash / OpenAI mini), окремо від підписки
- [ ] **Supabase:** новий проєкт для Lead Engine (URL + service key)
- [ ] **Vercel:** акаунт/проєкт для демо-сайтів
- [ ] **Домен для демо:** напр. `demo.aisystema.…` (купити, якщо немає)
- [ ] **Telegram-бот** для нотифікацій «🔥 відкрив» (токен від @BotFather) + твій chat_id
- [ ] **n8n:** URL інстансу на Contabo, куди імпортувати воркфлоу
- [ ] (пізніше) Opendatabot API key для директорів (Work.ua-напрям)
- [ ] (пізніше) Meta Ad Library: доступ до API для сигналу «крутять рекламу»
